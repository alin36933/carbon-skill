# ce-data — 碳足迹数据采集

## 一句话描述
帮助企业建立碳排放数据的采集、管理与质控体系。

## 企业主听得懂的大白话
"我第一步怎么把碳数据管起来"

## 目标用户
- 首次开展碳管理工作的企业环保/能源负责人
- 需要建立碳数据管理平台的企业IT及运营部门
- 面临碳排放报告/核查要求的企业
- 供应链碳排放管理需求的上游品牌方

## 核心能力
1. **碳数据采集方案设计**：针对电、天然气、油、煤、蒸汽等主要排放源，设计数据采集方案（含采集频次、计量点位、数据格式）
2. **碳数据管理平台搭建**：指导企业建立碳数据管理平台，涵盖数据录入、自动采集、汇总计算、报表生成等功能架构
3. **数据质量校验**：建立数据质量保障机制，包括数据完整性校验、异常值检测、数据交叉验证、缺失值处理
4. **碳数据溯源**：建立从原始计量数据到碳排放核算结果的可追溯链条，满足第三方核查要求

## 输入/输出

| 类型 | 内容 |
|------|------|
| **输入** | 企业组织架构与排放源清单、现有计量仪表情况、各排放源能源消耗数据、企业IT系统架构、碳核算边界 |
| **输出** | 碳数据采集方案、数据管理平台功能需求文档、数据质量校验规则、数据溯源方案、碳数据管理实施路线图 |

## 使用场景
- 企业刚启动碳管理，不知道从哪开始收集数据
- 企业的碳排放数据质量差，第三方核查时经常被质疑
- 企业需要搭建碳排放管理数字化系统
- 供应链上下游要求企业提供可靠的碳排放数据
- 企业准备参与碳交易，需要建立可核查的碳数据体系

## 技能说明
本技能聚焦碳管理的第一步——数据。技能覆盖从「排放源识别→数据采集方案→平台搭建→质量校验→数据溯源」的全流程，确保企业碳数据"算得清、说得明、查得证"。技能基于ISO 14064、GHG Protocol、中国碳排放核算指南等标准框架，但不过度深入核算公式本身，而是专注于数据采集与管理的实操方法论。不涉及具体碳核算软件产品的选型与实施。
