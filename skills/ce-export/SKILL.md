# ce-export — 碳关税/出口合规

## 一句话描述
帮助出口企业应对欧盟CBAM、电池法案、美国CCA等碳关税法规，完成碳合规申报与风险排查。

## 企业主听得懂的大白话
**"我的产品出口欧盟要不要交碳关税"**——帮你搞清楚出口到欧盟/美国要交多少碳税、怎么合规申报、怎么少交钱。

## 目标用户
- 出口欧盟/美国的外贸企业主
- 外贸公司合规/关务负责人
- 钢铁、铝、水泥、化肥、电力、氢能等高碳行业出口企业
- 电池及新能源汽车出口企业

## 核心能力
1. **欧盟CBAM申报指导**：碳边境调节机制（CBAM）申报流程、隐含碳排放计算、证书购买指导
2. **欧盟电池法案碳足迹**：动力电池/工业电池的碳足迹声明要求、标签合规
3. **美国清洁竞争法案（CCA）**：美国碳关税政策分析与合规应对
4. **出口碳合规检查**：产品碳足迹数据是否满足进口国要求，识别合规风险点
5. **合规成本测算**：模拟不同碳价情景下的碳关税成本，评估出口竞争力
6. **政策动态追踪**：主要经济体碳关税政策变化跟踪与分析

## 输入/输出

| 类型 | 内容 |
|------|------|
| **输入** | 出口产品类型、HS编码、出口目的地、产品碳足迹数据、生产工艺参数、电力排放因子、原材料来源 |
| **输出** | CBAM申报数据包（含隐含碳排放计算表）、碳关税成本测算报告、出口合规差距分析报告、合规整改建议书 |

## 使用场景
- **场景1**：钢铁/铝制品出口欧盟，CBAM过渡期已开始，需要按期提交季度报告
- **场景2**：电池出口欧盟，需要满足欧盟电池法案的碳足迹声明要求
- **场景3**：企业想评估美国清洁竞争法案（CCA）对出口业务的影响
- **场景4**：出口企业想全面检查产品是否满足各主要市场的碳合规要求

## 技能说明
碳关税是国际贸易中的新壁垒。欧盟CBAM（碳边境调节机制）已于2023年10月进入过渡期，2026年起正式征收碳关税；美国清洁竞争法案（CCA）也在推进中。本技能聚焦出口企业的碳合规需求，覆盖CBAM申报、欧盟电池法案碳足迹要求、美国CCA分析等核心场景，帮助企业准确核算出口产品的隐含碳排放，完成合规申报，量化碳关税成本，提升出口竞争力。
