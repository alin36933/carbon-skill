# ce-greenpower — 绿电绿证交易

## 一句话描述
指导企业如何购买绿电与绿证，满足合规要求并降低碳排放。

## 企业主听得懂的大白话
"怎么买绿电，买多少才合规"

## 目标用户
- 需要采购绿电/绿证的企业采购负责人
- 面临2026年6月强制消费令的控排企业
- 希望提升可再生能源使用比例的品牌方
- 出口型企业（需应对欧盟CBAM碳边境调节机制）

## 核心能力
1. **绿电交易指南**：提供绿电市场化交易的完整流程，包括交易主体准入、双边协商/集中竞价/挂牌交易等模式的操作指引
2. **绿证交易（GEC/I-REC）**：指导国内绿证（GEC）与国际绿证（I-REC）的购买渠道、价格对比与核销流程
3. **绿电消费合规**：解读2026年6月强制消费令的合规要求，帮助企业评估绿电消费是否达标
4. **企业绿电替代方案**：根据企业用电量、预算、区域电网清洁度，推荐最优的绿电/绿证组合方案

## 输入/输出

| 类型 | 内容 |
|------|------|
| **输入** | 企业年用电量、所在地区/电网区域、当前用电结构、合规目标、预算范围 |
| **输出** | 绿电采购方案建议、绿证配置方案、合规达标评估报告、绿电替代路径规划 |

## 使用场景
- 企业即将面临强制绿电消费要求，需要提前规划采购方案
- 出口企业需要I-REC绿证来应对欧盟CBAM
- 企业ESG报告需要披露绿色电力使用数据
- 企业希望从传统电力切换为绿电，但不确定如何操作

## 技能说明
本技能聚焦绿电绿证交易的全链路实操指导，涵盖从交易规则理解到合规达标的完整闭环。技能基于中国绿电交易市场政策（含2026年6月强制消费令）、绿证交易平台规则和国际绿证（I-REC）标准，为企业提供可执行的绿电采购与合规方案。不涉及绿电发电技术本身，而是专注于「购买端」的决策与执行。
