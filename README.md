# 节能降碳AI技能包 (Carbon-Skill)

让任何AI Agent拥有专业的碳管理能力，帮企业从碳排诊断到拿补贴，走完碳管理全流程。

## 概览

Carbon-Skill 是一套面向企业客户的节能降碳AI技能包，覆盖**诊断 → 对标 → 降本 → 合规 → 报告 → 补贴 → 供应链**七大环节。

每个技能都是一个独立的 Skill 文件夹，内含 `SKILL.md` 说明书，AI Agent 读取后即可获得对应领域的专业能力。

## 技能列表

| # | 命令 | 技能 | 一句话 | 企业主听得懂 |
|:-:|:----|:----|:------|:-----------|
| 1️⃣ | `/ce-diagnosis` | 企业碳排诊断 | 输入行业/规模，输出碳排画像 | "帮我算算我排多少" |
| 2️⃣ | `/ce-benchmark` | 同行业对标 | 你家比同行高还是低 | "我比同行多排了多少" |
| 3️⃣ | `/ce-cost-cut` | 降本路径推荐 | 绿电/设备改造/碳资产，怎么省钱 | "怎么省钱" |
| 4️⃣ | `/ce-compliance` | 合规自检清单 | 国标/碳税/碳配额，红黄绿预警 | "会不会被罚" |
| 5️⃣ | `/ce-report` | 碳足迹报告生成 | 行业专用报告自动生成 | "出个报告" |
| 6️⃣ | `/ce-incentive` | 政策补贴匹配 | 政府有什么补贴可以拿 | "能拿什么补贴" |
| 7️⃣ | `/ce-supplychain` | 供应链碳管理 | 帮客户算上下游的碳 | "上下游也得管" |

## 技能联动流程

```
用户进来说"帮我看看"
        ↓
  /ce-diagnosis 算碳排
        ↓
  /ce-benchmark 看同行 → 发现自己排高了
        ↓
  /ce-cost-cut 找降本方案 → 绿电/改造/碳资产
        ↓
  /ce-compliance 查合规 → 有没有风险
        ↓
  /ce-report 出正式报告
        ↓
  /ce-incentive 查补贴 → 能拿多少钱
        ↓
  /ce-supplychain 管上下游
```

## 安装

```bash
# 安装全部技能
npx -y skills add <repo>/carbon-skill -g --all

# 安装单个技能
npx -y skills add <repo>/carbon-skill --skill ce-diagnosis
```

## 知识库

`知识库/` 目录下包含结构化知识原子和方法论文档，可直接用于 RAG 检索或作为 AI 的 system prompt。

| 知识库模块 | 内容 |
|-----------|------|
| 政策法规/ | 最新碳管理政策、国标文件 |
| 排放因子/ | 分区域/分能源类型的排放因子 |
| 能效标杆/ | 各行业能效基准值/标杆值 |
| 案例库/ | 节能降碳典型案例 |
| 补贴政策/ | 各级政府补贴政策汇编 |
