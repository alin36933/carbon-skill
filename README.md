### 19个技能一览

#### 🟢 入门层：数据 → 诊断 → 降本
| 技能 | 做什么 |
|:----|:-------|
| 碳数据管理 | 数据采集方案、平台搭建 |
| 碳排诊断 | 输入行业/规模，输出碳排画像 |
| 节能诊断 | 设备能效评估、节能改造方案 |
| 降本方案 | 绿电替代/设备改造，算投入产出 |
| 绿电绿证 | 绿电采购、合规达标 |

#### 🔵 合规层：合规 → 报告 → 认证 → 对标
| 技能 | 做什么 |
|:----|:-------|
| 合规检查 | 国标/碳税/碳配额，红黄绿预警 |
| 碳足迹报告 | 行业专用碳足迹报告自动生成 |
| 产品碳足迹 | 产品全生命周期碳核算 |
| 碳认证 | 碳标签/碳中和/碳足迹认证 |
| 行业对标 | 对比行业平均水平，找出差距 |

#### 🟡 价值层：补贴 → 资产 → 交易 → 金融
| 技能 | 做什么 |
|:----|:-------|
| 补贴查询 | 匹配各级政府补贴政策 |
| 碳资产管理 | 配额台账、CCER评估 |
| 碳交易 | 配额买卖、交易策略 |
| 碳金融 | 质押融资、碳保险、碳期货 |

#### 🔴 战略层：路径 → ESG → 关税 → 供应链 → 普惠
| 技能 | 做什么 |
|:----|:-------|
| 碳中和路径 | 目标设定、路线图、零碳工厂规划 |
| ESG报告 | ESG报告编制、CDP/TNFD披露 |
| 碳关税合规 | CBAM申报、电池法案、美国CCA |
| 供应链碳管理 | 上下游碳足迹核算与优化 |
| 碳普惠 | 员工碳账本、消费者碳普惠 |
