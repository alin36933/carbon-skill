# 节能降碳AI技能包 (Carbon-Skill)

让任何AI Agent拥有专业的碳管理能力，帮企业从碳排数据采集到碳金融，走完碳管理全价值链。

## 概览

Carbon-Skill 是一套面向企业客户的节能降碳AI技能包，覆盖**数据采集 → 碳排诊断 → 节能诊断 → 降本路径 → 绿电替代 → 合规检查 → 碳足迹报告 → 产品碳足迹 → 碳认证 → 行业对标 → 政策补贴 → 碳资产管理 → 碳交易 → 碳金融 → 碳中和路径 → ESG报告 → 碳关税 → 供应链碳管理 → 碳普惠**19个环节。

每个技能都是一个独立的 Skill 文件夹，内含 `SKILL.md` 说明书，AI Agent 读取后即可获得对应领域的专业能力。

## 技能联动流程

```
企业想搞碳管理
        ↓
  /ce-data 数据采集 → 先把数据管起来
        ↓
  /ce-diagnosis 算碳排 → 知道自己排多少
        ↓
  /ce-energy 节能诊断 → 找省电省钱的地方
        ↓
  /ce-cost-cut 降本方案 → 绿电/改造/碳资产
        ↓
  /ce-greenpower 绿电绿证 → 买绿电满足合规
        ↓
  /ce-compliance 合规检查 → 有没有违规风险
        ↓
  /ce-report 出碳排报告 → 正式文件
        ↓
  /ce-product 算产品碳足迹 → 每个产品多少碳
        ↓
  /ce-certification 碳认证 → 贴上碳中和标签
        ↓
  /ce-benchmark 对标同行 → 知道自己水平
        ↓
  /ce-incentive 查补贴 → 能拿多少钱
        ↓
  /ce-carbon-asset 管碳资产 → 配额/CCER值多少
        ↓
  /ce-trading 碳交易 → 买卖配额获利
        ↓
  /ce-finance 碳金融 → 碳配额质押融资
        ↓
  /ce-strategy 碳中和路径 → 10年路线图
        ↓
  /ce-esg 出ESG报告 → 上市公司必备
        ↓
  /ce-export 碳关税合规 → 出口不被罚
        ↓
  /ce-supplychain 管供应链 → 上下游一起管
        ↓
  /ce-carbon-credit 碳普惠 → 员工碳账本
```

## 安装

```bash
# 安装全部技能
npx -y skills add <repo>/carbon-skill -g --all

# 安装单个技能
npx -y skills add <repo>/carbon-skill --skill ce-diagnosis
```

## 知识库

`知识库/` 目录下包含结构化知识原子和方法论文档，可直接用于 RAG 检索或作为 AI 的 system prompt。

| 知识库模块 | 内容 |
|-----------|------|
| 政策法规/ | 最新碳管理政策、国标文件 |
| 排放因子/ | 分区域/分能源类型的排放因子 |
| 能效标杆/ | 各行业能效基准值/标杆值 |
| 案例库/ | 节能降碳典型案例 |
| 补贴政策/ | 各级政府补贴政策汇编 |
