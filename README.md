## 📋 19个技能一览

### 🟢 入门层：数据 → 诊断 → 降本
| 技能 | 企业主听得懂 | 做什么 |
|:----|:-----------|:-------|
| `/ce-data` | "我第一步怎么把碳数据管起来" | 数据采集方案、平台搭建、质量校验 |
| `/ce-diagnosis` | "帮我算算我排多少" | 输入行业/规模，输出碳排画像 |
| `/ce-energy` | "我的电费还能省多少" | 设备能效评估、节能改造方案 |
| `/ce-cost-cut` | "怎么省钱" | 绿电替代/设备改造/碳资产管理，算投入产出 |
| `/ce-greenpower` | "怎么买绿电，买多少才合规" | 绿电采购、绿证交易、合规达标 |

### 🔵 合规层：合规 → 报告 → 认证 → 对标
| 技能 | 企业主听得懂 | 做什么 |
|:----|:-----------|:-------|
| `/ce-compliance` | "会不会被罚" | 国标/碳税/碳配额，红黄绿预警 |
| `/ce-report` | "出个报告" | 行业专用碳足迹报告自动生成 |
| `/ce-product` | "我的产品从原料到出厂排了多少碳" | 产品全生命周期碳核算 |
| `/ce-certification` | "能不能贴上碳中和标签" | 碳标签/碳中和/碳足迹认证 |
| `/ce-benchmark` | "我比同行高还是低" | 对比行业平均水平，找出差距 |

### 🟡 价值层：补贴 → 资产 → 交易 → 金融
| 技能 | 企业主听得懂 | 做什么 |
|:----|:-----------|:-------|
| `/ce-incentive` | "能拿什么补贴" | 匹配各级政府补贴政策 |
| `/ce-carbon-asset` | "我手里的碳配额值多少钱" | 配额台账、CCER评估、资产策略 |
| `/ce-trading` | "碳配额怎么买卖，什么时候卖最划算" | 配额交易、CCER交易、交易策略 |
| `/ce-finance` | "碳配额能拿去贷款吗" | 质押融资、碳保险、碳期货 |

### 🔴 战略层：路径 → ESG → 关税 → 供应链 → 普惠
| 技能 | 企业主听得懂 | 做什么 |
|:----|:-----------|:-------|
| `/ce-strategy` | "我到底怎么实现碳中和，分几步走" | 目标设定、路线图、零碳工厂规划 |
| `/ce-esg` | "上市公司要交的ESG报告怎么写" | ESG报告编制、CDP/TNFD披露 |
| `/ce-export` | "我的产品出口欧盟要不要交碳关税" | CBAM申报、电池法案、美国CCA |
| `/ce-supplychain` | "上下游也得管" | 上下游碳足迹核算与优化 |
| `/ce-carbon-credit` | "员工的减排行为能不能算成碳积分" | 员工碳账本、消费者碳普惠 |

## 🔄 全流程联动

```
企业想搞碳管理
        ↓
  /ce-data 数据采集 → 先把数据管起来
        ↓
  /ce-diagnosis 算碳排 → 知道自己排多少
        ↓
  /ce-energy 节能诊断 → 找省电省钱的地方
        ↓
  /ce-cost-cut 降本方案 → 绿电/改造/碳资产
        ↓
  /ce-greenpower 绿电绿证 → 买绿电满足合规
        ↓
  /ce-compliance 合规检查 → 有没有违规风险
        ↓
  /ce-report 出碳排报告 → 正式文件
        ↓
  /ce-product 算产品碳足迹 → 每个产品多少碳
        ↓
  /ce-certification 碳认证 → 贴上碳中和标签
        ↓
  /ce-benchmark 对标同行 → 知道自己水平
        ↓
  /ce-incentive 查补贴 → 能拿多少钱
        ↓
  /ce-carbon-asset 管碳资产 → 配额/CCER值多少
        ↓
  /ce-trading 碳交易 → 买卖配额获利
        ↓
  /ce-finance 碳金融 → 碳配额质押融资
        ↓
  /ce-strategy 碳中和路径 → 10年路线图
        ↓
  /ce-esg 出ESG报告 → 上市公司必备
        ↓
  /ce-export 碳关税合规 → 出口不被罚
        ↓
  /ce-supplychain 管供应链 → 上下游一起管
        ↓
  /ce-carbon-credit 碳普惠 → 员工碳账本
```
