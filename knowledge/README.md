# 🌿 碳管理知识库 (Carbon Knowledge Base)

本目录包含碳管理领域的结构化知识原子，覆盖政策法规、核算方法、行业标准、实战案例等维度。

## 目录结构

| 目录 | 内容 |
|------|------|
| `policies/` | 政策法规（国标、地方政策、国际法规） |
| `standards/` | 核算标准与方法论（ISO、GHG Protocol、国标） |
| `industries/` | 行业碳管理数据（钢铁、有色、电力、化工等） |
| `cases/` | 实战案例（企业碳管理、降本增效、碳交易） |
| `skills/` | 各AI技能的知识支撑（对应技能包的19个技能） |

## 数据格式

每条知识原子为 JSON 格式：

```json
{
  "id": "KN-0001",
  "title": "知识原子标题",
  "category": "政策法规/核算方法/行业数据/实战案例",
  "tags": ["碳足迹", "国标", "ISO"],
  "content": "知识原子正文内容",
  "source": "来源链接或引用",
  "date": "2026-07-24",
  "confidence": "high/medium/low"
}
```
