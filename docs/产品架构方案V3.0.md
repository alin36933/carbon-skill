# 节能降碳AI技能包 — 产品架构方案（V3.0）

## 一、产品定位

**一句话**：一套让普通人和中小企业主通过AI快速上手碳管理全流程的19步技能包。

**对标dbskill模式**：开源引流 → 线下课变现 → 口碑裂变
**差异化**：赛道更大（碳管理1099亿市场）、刚需更强（政策强制）、链条更全（从数据采集到碳金融全覆盖）

## 三、为什么这个模式能跑通

### 对企业主来说
- **听得懂**：每个技能对应一个企业主关心的实际问题
- **有结果**：直接出数据、出方案、出报告
- **能省钱**：降本路径直接算投资回报，补贴能拿多少钱一目了然
- **全链条**：从入门到碳金融，企业越做越深，技能包一直能用

### 对普通人来说
- **门槛低**：不需要碳管理专业背景，AI技能包帮你做专业判断
- **有工具**：拿这套技能包就能跟企业主对话、出方案
- **能变现**：学会后帮企业做碳管理服务，1对1培训12800元
- **有深度**：从简单诊断到碳金融，本事越学越大

### 市场够大
- 全国碳市场3378家重点排放单位，9大行业扩围后7000+
- 欧盟CBAM碳关税倒逼出口企业做碳管理
- 1099亿碳管理市场，品类空白
- 19个技能覆盖企业碳管理全生命周期，独此一家

## 四、技术实现

### 双版本策略
- **Coze版**：快速搭建原型，验证市场需求（利用已有旗舰版）
- **Skills标准版**：GitHub开源，一行命令安装，覆盖所有AI平台

### 知识库建设
- 政策法规库 → 最新政策+国标文件
- 排放因子库 → 分区域/分能源类型
- 能效标杆库 → 各行业基准值
- 补贴政策库 → 各级政府补贴汇编
- 案例库 → 节能降碳典型案例
