📖 使用教程：搭配各种AI平台

这个技能包是开源的，可以在任何AI平台使用。以下是主流平台的导入方法👇

🅰️ 在 Coze 中使用（推荐）

  1. 打开 Coze 官网，创建 Bot
  2. 在 Bot 配置中，点击「技能」→「导入技能」
  3. 选择本仓库 carbon-skill/skills/ 目录下的技能文件
  4. 把 knowledge/ 知识库导入 Bot 的知识库
  5. 配置好 Prompt 提示词，发布即可使用

💡 提示：技能包里的每个技能都有独立描述，Coze 会自动识别。

🅱️ 在 Dify 中使用

  1. 打开 Dify，创建应用
  2. 在「知识库」中上传 knowledge/ 目录下的 JSON 文件作为 RAG 数据源
  3. 在「工作流」中按需调用 skills/ 里的技能描述作为节点
  4. 配置 LLM 节点时，把技能描述写入 System Prompt

💡 提示：Dify 的知识库支持 JSON 格式直接导入，不需要额外转换。

🧠 在 ChatGPT / Claude 中使用

  1. 下载本仓库的 ZIP 包
  2. 打开 knowledge/ 目录下的 JSON 文件，把内容直接复制粘贴给 AI
  3. 告诉 AI：「你现在是碳管理专家，请根据以下知识库回答我的问题」
  4. 上传企业数据，AI 就能帮你做碳核算、出报告、查政策

💡 提示：可以用 GPTs 或 Claude Projects 把知识库设为固定上下文，一次配置长期使用。

💻 开发者集成

  1. Fork 本仓库到你的账号
  2. 按需调用 skills/ 下的技能描述，集成到你的 AI Agent 中
  3. 知识库 JSON 可直接用于 RAG 检索
  4. 支持二次开发，按你的业务场景定制
